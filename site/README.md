# موقع التكييف المركزي ومكافحة الحريق

موقع عربي RTL من صفحتين داخل ملف HTML مستقل، بتصميم متجاوب للهاتف والتابلت والكمبيوتر.

## التشغيل والتنزيل

- الملف النهائي: [`../index.html`](../index.html).
- افتح الملف مباشرة في المتصفح، دون تثبيت حزم أو تشغيل خادم.
- الصور والخطوط وGSAP وScrollTrigger وLenis مدمجة داخل الملف؛ لا يحتاج العرض أو التنقل إلى الإنترنت. الاتصال عبر واتساب يحتاج إلى الإنترنت وتطبيق/موقع واتساب.
- الصفحة الأولى: `#home`. الصفحة الثانية: `#services`.
- روابط مباشرة: `#home/about`، `#home/process`، `#services/hvac`، `#services/fire`، `#services/engineering`، `#services/contact`.
- زر «تنزيل نسخة الموقع» في التذييل يحمّل ملف `index.html` المستقل نفسه.
- للنشر: ارفع `index.html` إلى أي استضافة ثابتة. لا يتطلب إعداد إعادة توجيه للمسارات، لأن التنقل يعتمد على hash.

## ملاحظات مهمة قبل النشر

1. **لم يصل ملف الشعار الأصلي أو اسم تجاري محدد.** لذلك استُخدم عنوان النشاط «التكييف المركزي وحلول مكافحة الحريق» مع أيقونة تكييف مؤقتة؛ لا تُقدَّم الأيقونة على أنها شعار الشركة الحقيقي. استبدل `.brand` في موضعي الرأس والتذييل بالشعار المعتمد عند استلامه.
2. الصور مولّدة بالذكاء الاصطناعي لتوضيح الأنظمة وليست صورًا لمشروعات الشركة. أضيف هذا التنويه داخل الموقع. يمكن استبدالها بصور مشروعات حقيقية معتمدة.
3. أُدرج الرقمان اللذان قدّمهما المستخدم: **01092703355** و**01550562908**. رابط واتساب يستخدم الرقم الأول بالصيغة الدولية المصرية **201092703355**. لم يُتحقق من تسجيل الرقم على واتساب؛ يجب تأكيده قبل النشر.
4. لا توجد ادعاءات عن سنوات خبرة أو عدد مشروعات أو اعتمادات لم يقدّمها المستخدم.
5. النموذج **يجهّز رسالة ولا يرسلها تلقائيًا**. بعد التحقق من الاسم والهاتف والخدمة، يظهر رابط واتساب لمراجعة الرسالة وإرسالها، وزر لنسخها. لا يوجد backend أو حفظ بيانات في الموقع، ولا يُعرض نجاح إرسال زائف.
6. نطاق الضمان ومدته وأسعار الخدمات تُتفق مع العميل؛ لم تُخترع تفاصيل تجارية.

## ملفات المصدر

| الملف | الوظيفة |
| --- | --- |
| `template.html` | المحتوى العربي، الصفحتان، الرسومات الهندسية SVG، النموذج |
| `styles.css` | التصميم، اتجاه RTL، الاستجابة، تباين الألوان، حالات التفاعل |
| `app.js` | التنقل، التبويبات، نموذج واتساب، القائمة، تنزيل الموقع، الحركات |
| `assets/` | صورتان توضيحيتان والخطوط والمكتبات المثبّتة بإصدارات محددة |
| `build.py` | دمج الملفات والموارد والتراخيص في `../index.html` |
| `serve.py` | خادم معاينة محلي لا يعرّض ملفات المستودع |
| `test.cjs` | اختبارات المتصفح الآلية |
| `COMPONENT-EVALUATION.md` | تقييم المكتبات السبع وسبب الاختيار |

### إعادة البناء

```sh
python site/build.py
```

يستخدم البناء مكتبة Python القياسية فقط. بعد تعديل المصدر أعد تشغيل الأمر؛ ليست هناك حاجة إلى pnpm أو بناء موقع Magic UI الأصلي. تم إبقاء مشروع Magic UI القائم دون تعديل.

### المعاينة

```sh
python site/serve.py
```

المعاينة على المنفذ `3000`، مربوطة بـ `0.0.0.0` ومتوافقة مع بيئة Arena. يعرض الخادم الملف النهائي فقط، مع gzip، ولا يسمح بتصفح ملفات المشروع.

### الاختبارات

تحتاج الاختبارات إلى Playwright ومتصفح Chromium مثبتين في بيئة الاختبار، وليس لتشغيل الموقع:

```sh
# عند توفر playwright في node_modules
node site/test.cjs

# اختياريًا: تحديد متصفح أو خادم مختلف
CHROMIUM_EXECUTABLE=/path/to/chromium TEST_URL=http://localhost:3000 node site/test.cjs
```

تشمل الاختبارات: الصفحتين، التبويبات وأسهم لوحة المفاتيح باتجاه RTL، التحقق من الحقول والأرقام العربية، ترميز رسالة واتساب، الأسئلة الشائعة، قائمة الهاتف وEscape، زر الرجوع، مقارنة الملف المنزل بالبناء، والعمل محليًا عبر `file://` مع تعطيل الشبكة. تُفحص 35 حالة تجمع خمسة مسارات وسبعة عروض شاشة من 320 إلى 1920 بكسل لاكتشاف أي تمرير أفقي.

## الحركة وإتاحة الاستخدام

- GSAP للظهور المتدرج وانتقالات التبويبات، وScrollTrigger لظهور أقسام الصفحة.
- Lenis لتمرير الماوس السلس، مع الإبقاء على التمرير اللمسي الطبيعي.
- تعطيل الحركات والتمرير المخصص عند `prefers-reduced-motion`، والاستجابة لتغيير التفضيل أثناء التصفح.
- تنظيف GSAP contexts عند تغيير الصفحة لمنع تراكم الحركات.
- تبويبات ARIA مع roving tabindex، قائمة هاتف تدعم Escape ولوحة المفاتيح، labels لكل الحقول، رابط لتخطي التنقل، وحالة النموذج عبر `role=status`.
- إشعارات تراخيص Cairo وLenis مدمجة في بيانات `third-party-licenses` داخل الملف النهائي، وترويسات حقوق GSAP الأصلية محفوظة.
